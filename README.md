# ClipNote 智能剪贴板历史管理器

> 复制过的东西，随时找回来。零第三方依赖的剪贴板历史工具。

ClipNote 在后台自动记录你复制过的所有文本，提供搜索、一键复制、收藏、导出等能力。
只用 Python 标准库（`tkinter` + `sqlite3`）编写，无需安装任何第三方包。

## ✨ 功能

- **自动记录** — 后台轮询剪贴板，复制即入历史，无需手动保存
- **智能去重** — 30 秒窗口内重复复制自动合并，历史列表不被刷屏
- **一键复制** — 双击或选中后回车，立刻复制回剪贴板
- **实时搜索** — 顶部搜索框即输即搜，不区分大小写
- **星标收藏** — 重要内容打星，一键切换"只看收藏"
- **持久化存储** — 数据存 SQLite，重启不丢，最多保留 500 条
- **导出备份** — 全部历史可导出为 JSON 文件
- **跨平台** — Windows / macOS / Linux 均可运行（需自带 Tk 的 Python 3.8+）

## 🚀 快速开始

```bash
# 启动图形界面
python clipnote.py

# 无界面自测（验证数据库 / 去重 / 搜索逻辑）
python clipnote.py --selftest
```

**Windows 用户**：如果系统里没装 Python，推荐从 [python.org](https://www.python.org/downloads/) 下载官方安装包（安装时勾选 `tcl/tk and IDLE`）。

## 🖱️ 使用说明

| 操作 | 方式 |
|------|------|
| 复制历史 | 双击列表项，或选中后按 `Enter` |
| 搜索 | 顶部输入框直接输入，`Ctrl+F` 聚焦搜索框 |
| 清除搜索 | `Ctrl+L` |
| 收藏/取消收藏 | 选中后点「收藏」按钮，或按 `Ctrl+A` |
| 只看收藏 | 点工具栏「只看收藏」切换 |
| 删除单条 | 选中后点「删除」或按 `Delete` |
| 清空历史 | 点「清空」（可选保留收藏项） |
| 导出备份 | 点「导出」，生成 JSON 文件 |

## 🗂️ 数据位置

| 内容 | 路径 |
|------|------|
| 历史数据库 | `~/.clipnote/clipnote.db` |
| 导出备份 | `~/.clipnote/clipnote_export.json` |

## 🧰 技术栈

- Python 3.8+ 标准库
- `tkinter` — 图形界面
- `sqlite3` — 数据持久化
- 零第三方依赖，单文件可运行
